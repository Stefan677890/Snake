#Snake

A classic Snake game created by reyuller and Stefan677890.

#How to Play:
- An apple will randomly spawn somewhere on the screen.
- Move the snake to eat the apple.
- Each apple you eat will:
  - Increase the snake’s length
  - Increase the game speed slightly
- Avoid hitting the walls — colliding with a wall will end the game.
